Paynote for Windows — store computer
====================================

This is the shop program. It does not need the internet.
Sales, stock, products, photos and profits are saved on THIS computer.

Install
-------
1. Copy the Paynote folder onto the store PC (Desktop or C:\Paynote).
2. Open the folder and double-click Paynote.exe.
3. Windows may say “Windows protected your PC”. Click More info, then Run anyway.
4. The Paynote window opens on this computer (localhost).
   Store password default is 1234. Staff desk PIN default is 1234.

This computer and Wi‑Fi
-----------------------
Paynote opens on the store PC automatically.

On that same Wi‑Fi, phones and other computers open the Wi‑Fi address
shown on the password screen and under Company / Sales, for example:

  This computer:     http://127.0.0.1:8080
  Phones on Wi‑Fi:   http://192.168.x.x:8080

Everyone uses the same store password (default 1234).

If a phone cannot open it, allow Paynote on private networks when Windows asks.

Where data is saved
-------------------
C:\Users\<their-name>\AppData\Roaming\Paynote\database

Keep that folder if you move the program. It is the shop book.

No internet is required after it is on the PC.
